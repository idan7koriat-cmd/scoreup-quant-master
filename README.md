# ScoreUp: Your Psychometric Edge

Build a modern, high-converting Psychometric Quantitative Reasoning (חשיבה כמותית בפסיכומטרי) learning platform named "ScoreUp" in Hebrew (RTL layout).

Key Sections & Features to include:

1. BRANDING & HERO SECTION (Inspired by LexiBoost layout):

- Platform Name: "ScoreUp"

- Headline: "ScoreUp — שפר את הציון בחלק הכמותי בפסיכומטרי"

- Subtitle: "למידה חכמה ותרגול ממוקד עם AI, פתרונות מפורטים שלב-אחר-שלב וניתוח ביצועים בזמן אמת."

- Call-to-Action Buttons: "התחל לתרגל חינם" (scrolls to practice engine) and "למה ScoreUp?"

- Stat Badges: "+20-40 נקודות לשיפור", "מאגר שאלות מעודכן", "תרגול בזמן אמת".

2. INTERACTIVE QUANTITATIVE PRACTICE ENGINE (Core MVP Component):

- Interactive Question Card supporting math equations using KaTeX (fractions, powers, roots, algebra, geometry).

- 4 multiple-choice options (תשובות אמריקאיות).

- Live countdown timer for each question (1:00 minute default).

- Instant answer feedback: Selected option turns green if correct, red if wrong.

- Expandable "פתרון מפורט" (Detailed Solution) block revealing step-by-step math solution after submitting an answer.

- "השאלה הבאה" (Next Question) navigation button.

3. MOCK DATA:

- Populate the system with 3 realistic psychometric quantitative questions (e.g., percentages, algebra, geometry) formatted cleanly with KaTeX math syntax.

4. DESIGN & STYLING:

- Sleek, high-contrast modern UI with ScoreUp branding (clean whites, deep tech blues/purples, vibrant green for correct answers).

- Fully responsive and Hebrew RTL native.
